====================================
ORDENADOR DE ARCHIVOS - README.txt
====================================

Descripción:
------------
Este programa organiza automáticamente los archivos dentro de una carpeta, 
clasificándolos en subcarpetas según su tipo (imágenes, PDF, videos, etc.).

Uso:
----
1. Ejecuta el archivo `main.exe` ubicado en la carpeta `\dist`.
2. Haz clic en "Buscar carpeta" y selecciona la carpeta que deseas ordenar.
3. Marca los tipos de archivo que quieres organizar.
4. Haz clic en "Confirmar selección".
5. Los archivos serán movidos a subcarpetas dentro de la carpeta seleccionada.
6. Se mostrará un mensaje indicando que el proceso ha terminado.

Tipos soportados:
-----------------
- Imágenes: .jpg, .jpeg, .png
- PDF: .pdf
- Videos: .mp4, .avi, .mov
- Documentos Word: .doc, .docx
- Textos: .txt, .md
- Otros: cualquier archivo que no encaje en las categorías anteriores

Notas importantes:
------------------
- Los archivos se mueven, no se copian.
- El programa modifica directamente el contenido de la carpeta seleccionada.
- No hay opción de deshacer.
- No es necesario instalar nada. Solo ejecutar.

====================================
FILE SORTER - README.txt
====================================

Description:
------------
This program automatically organizes files within a folder,
sorting them into subfolders based on their type (images, PDFs, videos, etc.).

Usage:
------
1. Run the `main.exe` file located in the `\dist` folder.
2. Click on "Search folder" and select the folder you want to organize.
3. Check the file types you want to sort.
4. Click on "Confirm selection".
5. The files will be moved into subfolders within the selected folder.
6. A message will appear once the process is complete.

Supported file types:
---------------------
- Images: .jpg, .jpeg, .png  
- PDF: .pdf  
- Videos: .mp4, .avi, .mov  
- Word Documents: .doc, .docx  
- Text: .txt, .md  
- Others: any file that doesn’t fit the categories above

Important notes:
----------------
- Files are moved, not copied.  
- The program directly modifies the contents of the selected folder.  
- There is no undo option.  
- No installation required. Just run the executable.
